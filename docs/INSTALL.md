# 在另一台电脑上安装

当前推荐Windows 10／11 x64完整桌面安装版。无需提前安装Python，无需云端API密钥；完整包自带CPU PyTorch、GPT-SoVITS、基础模型和默认双音色。

## 完整安装

1. 从[发行页面](https://github.com/honokaoshi83-max/iracing-chinese-assistant/releases/latest)下载完整ZIP，或将全部`.zip.001`、`.zip.002`分卷放在同一目录，用7-Zip打开`.001`解压。不要逐卷单独解压。
2. 运行`iracing-chinese-assistant-0.2.8-setup.exe`，配套`iracing-chinese-assistant-0.2.8-setup-1.bin`必须与EXE同目录。选择可写目录，建议预留至少10GB磁盘与6GB可用内存；实际负载受CPU及同时运行的软件影响。
3. 安装结束默认提供Simulator Controller一键安装并接入，需要联网；已有安装优先复用，原配置先备份。缺少该组件会缺少邻车、旗号和部分策略播报。
4. 打开助手会自动启动语音和已接入的SC组件；分别试听工程师和观察员，赛前预热固定缓存，再进入iRacing。无需另外启动GPT-SoVITS网页。

默认工程师为克洛琳德，观察员／策略师为芙宁娜；两角色共用一个推理引擎。首次未缓存内容可能等待较久，缓存命中会更快。音色文件来自第三方，来源与使用条件见[第三方说明](../THIRD_PARTY.md)。

## 实时播报按键

首次安装默认无绑定。在首页点击“绑定播报按键”，松开所有键后按下目标按钮，完成学习。不要假定其他设备的PS键编号相同；升级保留旧绑定。

单次按下触发状态摘要，长按不重复，默认八秒防重复。快车和左右并排等安全提醒优先于状态摘要，可打断摘要或确认音。按键只用于本助手，不修改游戏控制配置，不启用麦克风或云端对话。

## 旧版升级

0.2.4、0.2.5、原始0.2.6和0.2.7构建使用对应的0.2.8增量补丁。先退出驾驶会话和托盘界面，再选择原安装目录；不要选择空目录。更新器校验程序文件、备份并保留个人设置、缓存与复盘。

如果程序文件已被手动修改，更新器会停止并指出文件，不要关闭校验强行覆盖。后续本地测试构建不一定匹配原始0.2.6，可使用完整版安装到新目录验证。详见[本版安装说明](SETUP_0.2.8.md)。

## 日志与验收

侧栏“诊断日志”可打开运行日志。后台日志位于安装目录`work/race-voices`，组件安装日志位于`logs/simulator-install.log`。应用内更新是用户手动检查，不会在驾驶中自动安装。

安装后的实体按键、实际音色、游戏内提醒和长时间比赛需要现场测试。源码安装器的自动验证与隔离目录测试不能替代另一台设备验收。

## 早期源码版

较早源码版使用`安装.cmd`、`启动.cmd`，可能默认系统语音，需要另行下载角色环境；它与当前完整桌面安装版不是同一套安装步骤。新设备优先使用上面的完整安装版。
