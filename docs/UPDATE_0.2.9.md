# 0.2.9 补丁升级

## 已有 0.2.4—0.2.8

在软件左下角点击“检查更新”，找到匹配补丁后点击下载并更新。先退出驾驶会话，更新器会关闭界面、备份并更新程序，随后重新打开。

也可以在本发行页面下载文件名中 `update-from-当前版本` 对应的 EXE，运行后选择原安装目录。不要选择空目录，不要使用其他版本的补丁。原始 0.2.6 后经手动改动的开发构建不一定匹配；校验失败会停止，不能绕过。

升级保留个人设置、方向盘绑定、模型、缓存与复盘，不重复下载 Python、PyTorch 或默认音色。本次只有增量补丁，没有新的完整安装包。

## 首次安装

先从 [0.2.8 发行页面](https://github.com/honokaoshi83-max/iracing-chinese-assistant/releases/tag/v0.2.8) 下载完整安装文件并安装，再应用从 0.2.8 升级的 0.2.9 补丁。

## 新的检查逻辑

0.2.9 会从 GitHub 正式发行记录中查找适合当前版本的最新补丁，下载后核对大小和 SHA-256。没有匹配补丁时保留当前版本，不自动下载完整安装包。检查由用户发起，驾驶时不会自动安装更新。

补丁日志在安装目录 `.updates` 内；日常运行日志可从侧栏“诊断日志”打开。
