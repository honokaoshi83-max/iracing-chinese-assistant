# 0.2.9 更新说明

发布日期：2026-10-19。

## 补丁更新

- 检查更新时读取本项目 GitHub 正式发行记录，按版本选择适合当前安装版本的最新补丁，不受某个发行版仅提供完整包的影响。
- 点击“下载补丁并更新”后只下载对应补丁；没有匹配补丁时明确提示并保留当前版本，不自动下载完整安装包。
- 保留下载地址、大小及 SHA-256 校验；更新前校验原文件，自动备份。保留按键绑定、音量、音色、缓存、策略与复盘。
- 提供 0.2.4、0.2.5、原始 0.2.6、0.2.7、0.2.8 到 0.2.9 的对应补丁。运行环境和默认模型不变，无需重复下载。

## 播报修复

- 正赛方格旗改为玩家完赛确认后播报，避免领跑者结束时提前判定玩家比赛结束。优先使用个人旗号；缺失时结合过线和会话阶段判断。
- 修复带过线计时复位证据的“成绩先更新、圈数后更新”漏报；官方圈数与成绩对应时允许确认连续完全相同成绩。出场圈旧成绩不作为最快圈基准。
- 修复组件静音请求导致圈速被打断后重播的问题。普通语音排队；快车、左右并排与净空安全提醒仍优先，可打断手动摘要。
- 正赛及 Time Trial 不再朗读详细复盘，保存成功后仅播报：“复盘文本已保存，请进入软件查看。”详细内容仍保存在软件与复盘文件中。
- 保留芙宁娜圈速／旗号／邻车和克洛琳德车辆状态／手动摘要的分工，以及单次通讯键和八秒防重复设定。

257 项后端、55 项桌面回归通过。实际补丁 EXE、隔离目录启动退出和远程文件校验结果见发行附件 VALIDATION.json。新完赛与首圈修复仍需游戏内实测，自动测试不能替代实体按键和游戏验收。
