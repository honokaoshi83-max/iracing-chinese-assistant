# 0.2.8 安装与升级

## 新设备完整安装

下载完整ZIP，或将`.zip.001`、`.zip.002`全部分卷放在同一目录，用7-Zip打开`.001`解压。不要逐卷分别解压。

运行`iracing-chinese-assistant-0.2.8-setup.exe`，配套`iracing-chinese-assistant-0.2.8-setup-1.bin`必须与EXE同目录。完整安装内含本地语音运行环境与默认双音色。首次播报键未绑定，请在首页绑定。

安装结束默认提供Simulator Controller一键安装并接入，需要联网；已有安装优先复用。未安装该组件会缺少邻车、旗号和部分策略功能。首次使用建议预热固定缓存。

## 已安装旧版

退出驾驶会话、结束其他任务，并从托盘退出界面。运行匹配旧版本的`iracing-chinese-assistant-0.2.8-update-from-0.2.4.exe`、`update-from-0.2.5.exe`、`update-from-0.2.6.exe`或`update-from-0.2.7.exe`，选择原安装目录。不要选择空目录。

更新器先验证原文件，备份后替换程序；保留个人设置、绑定、音量、自定义音色、缓存和复盘，备份放在安装目录`.updates`。更新完成后重新打开应用，组件随应用启动；应用关闭时不单独恢复后台。

0.2.6补丁针对原始0.2.6完整安装构建。后续本地测试补丁、手动改文件或开发目录可能与原始构建不同，更新器会停止覆盖并指出文件；不要关闭校验强行更新，可使用完整版安装到新目录测试。

新版可在侧栏或托盘手动“检查更新”。只有GitHub正式发布且提供匹配附件后，联网检查才会提供更新；它不会在驾驶中自动安装。

日志入口是“诊断日志”；后台日志位于安装目录`work/race-voices`，组件安装日志位于`logs/simulator-install.log`。另一台设备的实际安装与游戏联动仍需验收。

## 应用与组件启停

打开应用自动启动语音，随后启动已接入的SC组件。关闭窗口会收起到托盘；选择“退出应用并关闭组件”才会全部退出。应用异常结束时自动清理所属组件。独立手动启动的外部SC保留。
