# 0.2.8 更新说明

发布日期：2026-10-18。

## 应用与组件同步启停

- 打开应用自动启动语音、遥测和守护进程；语音就绪后启动已完成接入的Simulator Controller。
- 应用未运行时，独立启动脚本拒绝启动后台。
- 窗口收起到托盘仍继续运行；选择“退出应用并关闭组件”同步关闭所属组件。
- 异常退出也会清理组件。启动代次、PID、进程创建时间和路径共同校验，快速重开等待旧代次退出。
- 独立手动启动的外部Simulator Controller保留，避免误关其他实例。
- 原有按键绑定、音量、音色、缓存和复盘保留；角色职责、圈速及安全优先级不变。

## 安装与升级

提供完整安装包及0.2.4、0.2.5、原始0.2.6、0.2.7到0.2.8的对应补丁。补丁验证原文件并自动备份；开发目录或手动修改版本可能不匹配，请勿绕过校验。

## 验证范围

236项后端与51项桌面回归通过。本机实际验证打开应用启动、正常退出关闭、强制结束清理、立即重开恢复以及私人设置保持一致。发布安装文件另行执行全新安装、覆盖安装与四个旧版本补丁验收；结果随VALIDATION.json发布。另一台设备及游戏内、实体按键仍需现场测试。
