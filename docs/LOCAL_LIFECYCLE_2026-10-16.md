# 应用与组件联动（本地开发更新）

- 打开应用后自动启动本地语音；就绪后启动已经接入的 Simulator Controller。
- 应用未启动时，后台启动脚本拒绝启动组件。
- 收起到托盘继续运行；从托盘退出应用时同步关闭助手管理的组件。
- 应用异常退出时，由守护进程检查 PID、进程创建时间和可执行文件，关闭所属组件，避免 PID 重用造成错误判断。
- 保留首页手动启停、现有按键绑定、八秒防重复、音色分工和播报规则。
- 已独立手动启动的外部 Simulator Controller 保留，不作为本应用拥有的实例关闭。

本次修改纳入0.2.8安装版与更新补丁。实体按键与游戏内播报仍由用户验收。

## 验证结果

- 236 项后端测试、51 项桌面测试通过，包含按键保护与安全提醒回归。
- 新构建 EXE 已部署本机；桌面快捷方式指向当前部署。
- 应用关闭时独立启动脚本返回失败，没有启动任何组件。
- 实际打开 EXE 后，语音、遥测、守护进程及 Simulator Controller 正常启动。
- 正常退出后，相关进程全部关闭。
- 强制结束应用并立即重新打开，新启动代次能够等待旧组件退出并恢复就绪。
- 强制结束应用且不重新打开，所属组件自动清理，无进程残留。
- 按键绑定、播放音量、音色、轮胎和情绪设置文件哈希均保持一致。
- 本机启动文件夹、相关注册表 Run 项和计划任务未发现播报助手／语音／SC 的开机自启项。

收起到托盘仍表示应用正在运行。需关闭全部组件时选择“退出应用并关闭组件”，也可执行应用的 `--quit` 参数请求正常退出。独立手动启动的外部 SC 实例仍保留。
