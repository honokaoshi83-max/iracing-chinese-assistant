更新日期：2026-10-27。用途：个人驾驶时的中文车内播报。本文件是当前唯一的进度说明；仓库根目录的`项目进度.md`是0.2.5时期的历史快照。

## 角色与架构

| 内容 | 默认音色 |
| --- | --- |
| 圈速、周围赛车、旗号、天气、策略与计时赛复盘 | 芙宁娜 |
| 赛车状态、燃油、轮胎、维修、赛道介绍、通讯按键摘要 | 克洛琳德 |

前后车按本场参赛编号播报：1号“一号”、11号“十一号”；保时捷911等车型代号按名称语境读“九幺幺”。两个角色各介绍一次。退出语音为“本次比赛结束，期待下一次合作”。

Simulator Controller的三个助手经共享Voice Server播放，本地遥测模块通过共享播报标记避让；所有音频并非同一个播放进程。两种音色共用GPT-SoVITS推理引擎，使用CPU，按需切换模型。当前情绪主要通过节奏调整，没有配置完整的情绪参考录音。

## 功能与边界

| 功能 | 当前实现与限制 |
| --- | --- |
| 每圈报时 | 芙宁娜口语播报圈速及比较；0.2.9修复成绩先于圈数更新的漏报，官方圈数与成绩对应时确认连续完全相同成绩 |
| 中文名称 | 537条赛道／布局、192条车辆／版本及6个别名，共735条中文前端检查；不等于逐条听感验收 |
| 邻车与旗号 | Simulator Controller及本地旗号模块；快车与并排安全提醒优先 |
| 车辆与维修 | 维修要求、倒计时、发动机告警与事故线索；不猜损伤部位或百分比 |
| 轮胎 | 冷胎压设置、可用实测胎压，以及进站更新的胎温与胎纹余量；不是所有车型全程实时可读 |
| 燃油 | 至少两份有效完整圈样本后估算油耗及续航，给出燃油进站建议 |
| 已选进站服务 | 报告游戏当前选择，如“当前进站服务：加油二十升、更换四条轮胎、快速维修” |
| 赛事策略（测试中） | 独立功能页、主动开关，默认关闭；用于初步燃油计划与遥测修正，不自动修改游戏服务，不求解综合最优策略 |
| 自定义音色 | 两个角色组可选择／导入自定义音色，默认音色不可删除；需要兼容模型和参考音频，不保证任意GPT-SoVITS版本都可导入 |
| 缓存与恢复 | 固定语音预热、动态缓存、守护恢复；不强杀正在执行的模型调用 |
| 联网更新 | 用户手动检查GitHub版本，校验地址、大小与SHA-256后下载对应增量更新；不是启动时自动检查 |

前方慢车识别限制到150米，保留已有更短个人设置。动态天气读取与换胎建议仍有字段和实测限制，不能当作可靠的未来天气预测。轮胎提醒阈值也不是各车型官方最优值。

## 实时播报按键

首次安装默认为无绑定；首页点击绑定后松开所有按键，再按目标按钮。升级保留绑定。当前使用WinMM，支持设备前32个按钮，设备序号可能随连接顺序变化；尚未使用稳定设备GUID，不支持任意键盘键或方向帽。

单次按下触发，默认八秒防重复，处理中不重复排队。监听与分发独立于SDK读取、复盘和语音生成；驱动读取异常恢复，临时配置写入失败保留最后有效绑定。旧播报取消不会清除新确认音。

优先级：**快车／左右并排及净空安全提醒 > 手动状态摘要 > 其他旗号和普通信息**。安全提醒可打断摘要及确认语；安全播报进行时按键仍可接收，但确认音不抢断它。摘要中途被安全提示打断后可再次按键查询。

通常先播本地缓存“正在整理具体数据，即将开始播报”，随后播车辆告警、油量、续航和已选服务；没有策略时不说“当前没有策略方案”。不开麦克风，不调用云端模型，不写游戏控制配置。

按键保护和安全优先级有独立回归测试与后续修改约束，不能替代实体短按、设备重连和长时比赛验收。

## 自动复盘

适用于正赛和Time Trial；练习、排位不自动生成这套评价。Time Trial至少记录两个完成圈才生成文本，不足五个计时圈不作稳定性评级。

一级“复盘”页面展示最近一次比赛及完整评价；表格每行三组字段，整页不滚动，评价区随文字增长从约1:5扩大到最大2:3。历史TXT和JSON全部保留在安装目录的“复盘”文件夹。

记录真实时间、赛道、布局、模式、车辆、比赛总用时或已记录用时、圈数、最快有效圈、有效平均圈速、波动率与犯规情况；正赛增加排名、发车名次及变化，没有正式结果时明确是最后观测值。

圈速波动率＝总体标准差÷平均圈速×100%。不超过0.75%为稳定，超过0.75%且不超过2%为有一定波动，超过2%为不稳定。这是助手自定参数，不是官方赛车评分。

评价按用户格式显示：“有效计时圈的圈速波动率为1.29%，圈速有一定波动。（0.75%内为稳定；0.75%至2%为有一定波动；超过2%为不稳定）”。括号仅文本显示，不朗读；JSON保留完整公式、精确边界和规则版本。

全部计时圈包含有用时的犯规圈，有效圈另算；无用时犯规圈只计入犯规比例，不编造圈速。取消单个无效圈自动降级。中位数与MAD辅助描述明显慢圈，不删数据、不猜慢圈原因。语音与文本共用稳定性及前后段趋势规则。

提前退出时，若SDK提供可靠剩余时间，等待预计结束后分析已记录数据；重连继续采集，后台重启后保留等待。无法确认退出后的实际赛况与最终名次，缺少可靠剩余时间时明确标注退出快照。自0.2.9起详细评价不朗读，保存成功由芙宁娜说“复盘文本已保存，请进入软件查看。”不分析燃油和轮胎。

详见[复盘说明](../REVIEWS.md)。

## 安装与发布

应用使用PySide6。页面包括运行概览、赛事策略（测试中）、音色管理、复盘、诊断日志。首页包含播报设置、实时播报按键、固定缓存预热和中部组件安装入口。

完整安装版内含Python、CPU PyTorch、GPT-SoVITS、基础模型及默认双音色，无须另开语音网页。Simulator Controller通过联网引导下载、基础配置并接入；缺少该组件会缺少邻车与部分策略播报。

完整下载：[v0.2.8](https://github.com/honokaoshi83-max/iracing-chinese-assistant/releases/tag/v0.2.8)，安装说明见[0.2.8安装与升级](../SETUP_0.2.8.md)。已安装0.2.4至0.2.8时，用应用内“检查更新”获取0.2.9补丁，见[0.2.9补丁升级](../UPDATE_0.2.9.md)。补丁保留个人设置、绑定、音量、音色、缓存及复盘；0.2.6补丁仅适用于原始安装构建，手动修改过程序文件时会停止覆盖。

日志入口是“诊断日志”；完整后台日志位于安装目录的`work/race-voices`，组件安装日志位于`logs/simulator-install.log`。源码与GitHub不上传私人日志、设置、复盘或模型。
